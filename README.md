# 📊 AI Data Analysis Assistant

An interactive web-based data analysis application built with **Python and Flask** that allows users to upload CSV datasets and automatically generate data-quality reports, statistical summaries, visualizations, insights, recommendations, and downloadable PDF reports.

🔗 **Live Demo:** https://ai-data-analysis-assistant.onrender.com/

🔗 **GitHub Repository:** https://github.com/devashreeb07/AI_Data_Analysis_Assistant



## 📌 Project Overview

The AI Data Analysis Assistant simplifies the initial stages of data analysis by automating common exploratory data analysis tasks.

Users can upload a CSV dataset, and the application automatically analyzes the data and presents the results through an easy-to-understand web interface.

The application is designed to help users quickly understand dataset structure, identify data-quality issues, explore numerical patterns, visualize relationships, and generate useful recommendations.



## 🎯 Objectives

- Automate basic exploratory data analysis
- Identify missing values and duplicate records
- Generate descriptive statistics
- Analyze numerical and categorical variables
- Identify important correlations and patterns
- Generate automatic data insights
- Provide actionable recommendations
- Create visualizations automatically
- Generate downloadable PDF analysis reports



## ✨ Features

### 📁 CSV Upload
- Upload CSV datasets through the web interface
- Automatically reads and processes the uploaded dataset

### 🔍 Data Quality Analysis
- Total rows and columns
- Missing-value detection
- Duplicate-record detection
- Column data-type identification

### 📊 Statistical Analysis
- Descriptive statistics for numerical columns
- Mean, median, minimum, maximum, and standard deviation
- Identification of important numerical patterns

### 📈 Data Visualization
Automatically generates visualizations such as:

- Scatter plots
- Correlation heatmaps
- Categorical distribution charts

### 💡 Automatic Insights
The application identifies meaningful patterns from the uploaded dataset, including:

- Strong correlations
- Important numerical trends
- Categorical patterns
- Dataset-specific observations

### 🎯 Recommendations
Provides automatically generated recommendations based on the detected patterns in the dataset.

### 📄 PDF Report
Users can generate and download a PDF report containing the analysis results.
